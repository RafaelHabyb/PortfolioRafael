## 💻 Projetos em destaque

### Perguntas Bíblicas

Projeto de estudo com dez perguntas e diferentes campos de formulário, criado para praticar a estruturação de páginas em HTML.

A versão original utiliza apenas HTML e permite preencher respostas, ainda sem correção automática ou pontuação.

[Explorar demonstração →](https://rafaelhabyb.github.io/PortfolioRafael/projetos/perguntas-biblicas.html)

### Exercícios em C

Atividades acadêmicas para desenvolver lógica de programação e consolidar conhecimentos em estruturas de decisão, repetição, vetores, matrizes e structs.

[Conhecer o repositório →](https://github.com/RafaelHabyb/ProjetoEmC)
